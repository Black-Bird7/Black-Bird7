# Setup

1. Open your profile repository:
   `https://github.com/black-bird7/black-bird7`

2. Upload these files while keeping the same paths:
   - `README.md`
   - `about-dark.svg`
   - `about-light.svg`
   - `profile.jpg`
   - `.github/workflows/snake.yml`

3. Commit the changes to `main`.

4. Open **Actions → Generate Contribution Snake** and run it once with
   **Run workflow**.

5. After it succeeds, the `output` branch will contain the generated snake.

6. The README will then load:
   `https://raw.githubusercontent.com/black-bird7/black-bird7/output/github-contribution-grid-snake.svg`

Important:
- The contribution/streak/activity widgets use your real GitHub username.
- Do not invent commits, stars, projects, certifications, or achievements.
- Pin your strongest real repositories on your GitHub profile.
